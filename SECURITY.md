# Security

API Acre never asks users to disclose private keys, seed phrases, wallet recovery
material, authentication cookies, or unrelated credentials.

For a security or payment-integrity concern involving API Acre, email
[hello@apiacre.com](mailto:hello@apiacre.com) with the affected public endpoint,
expected behavior, observed behavior, and a minimal non-destructive reproduction.
Do not include secrets or personal data.

This repository is a documentation and discovery hub. It does not operate a bug
bounty or promise rewards. Avoid destructive testing, high-volume traffic, access
to other users' data, or attempts to bypass payment on the production service.
